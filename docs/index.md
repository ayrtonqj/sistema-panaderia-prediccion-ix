# Documentacion del Sistema — Panaderia Victoria

Sistema de Gestion Predictiva para Panaderia Victoria.
Tesis de investigacion sobre la aplicacion de Machine Learning para la optimizacion de produccion en panaderias.

## Modulos del sistema

| # | Modulo | Archivo | Descripcion |
|---|---|---|---|
| 1 | Dashboard y KPIs | [MODULO_1_DASHBOARD.md](MODULO_1_DASHBOARD.md) | Panel principal con indicadores en tiempo real, alertas, recomendaciones ML |
| 2 | Ventas y Venta Rapida | [MODULO_2_VENTAS.md](MODULO_2_VENTAS.md) | Punto de venta, carrito, facturacion, pan del dia anterior |
| 3 | Produccion y Predicciones ML | [MODULO_3_PRODUCCION.md](MODULO_3_PRODUCCION.md) | Registro de produccion, automaticos, modelos predictivos (OE2/OE3/OE4/OE6) |
| 4 | Inventario y Ordenes de Compra | [MODULO_4_INVENTARIO.md](MODULO_4_INVENTARIO.md) | Gestion de insumos, proveedores, precios inteligentes, ordenes automaticas |
| 5 | Control de Perdidas y Reportes | [MODULO_5_PERDIDAS.md](MODULO_5_PERDIDAS.md) | Eficiencia, analisis de mermas, reportes financieros, ciclo del pan recuperado |
